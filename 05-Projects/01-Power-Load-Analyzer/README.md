# Power Load Analyzer

A beginner-level Python project for analyzing electricity load data.

## Goal

Use Python to analyze electricity consumption data and visualize load patterns.

## Planned Features

- Read electricity data from CSV
- Calculate daily electricity consumption
- Find peak and minimum load
- Plot load curves
- Analyze basic load patterns

## Tools

- Python
- Pandas
- Matplotlib

## Learning Goals

Through this project, I want to learn:

- Basic Python data processing
- Pandas
- Data visualization
- Basic concepts of electrical load
